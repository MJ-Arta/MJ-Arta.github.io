This is a personal tool used only by the operator of the YouTube channel Toto & CoCo. It is not distributed to the public and does not access anyone else's account.

2. 접근하는 정보

  • youtube.upload — 운영자 본인의 채널에 영상을 업로드하기 위해 사용합니다.
  • youtube.readonly — 업로드한 영상의 제목·설명·태그·공개 상태가 의도한 값으로 저장됐는지 되읽어 확인하기 위해 사용합니다.

이 두 가지 외의 Google 데이터(이메일 본문, 연락처, 드라이브 파일, 프로필 정보 등)에는 접근하지 않으며 요청하지도 않습니다.

The app requests only the two scopes above. It does not request or access any other Google data such as mail, contacts, Drive files, or profile information.

3. 저장하는 정보와 저장 위치

  • Google OAuth 토큰(액세스 토큰·리프레시 토큰)을 운영자 개인 컴퓨터에만 저장합니다.
  • 저장 경로는 운영자 계정의 사용자 폴더 안이며, 파일 권한은 소유자 전용으로 제한합니다.
  • 서버가 없습니다. 토큰이나 어떤 개인정보도 외부로 전송·업로드·백업되지 않습니다.

Google OAuth tokens are stored only on the operator's own computer, in the operator's user folder with owner-only file permissions. There is no server; no token or personal data is transmitted, uploaded, or backed up anywhere.

4. 제3자 제공

어떤 정보도 제3자에게 판매·공유·양도하지 않습니다. 광고·분석·추적 도구를 사용하지 않습니다. 정보를 전송하는 대상은 업로드 요청을 받는 Google/YouTube API 뿐입니다.

No data is sold, shared, or transferred to third parties. No advertising, analytics, or tracking is used. The only external service contacted is the Google/YouTube API itself.

5. 보관 기간과 삭제

토큰은 운영자가 파일을 삭제하거나 Google 계정에서 권한을 철회하면 즉시 무효가 됩니다. 별도의 보관 기간을 두지 않습니다.

Toto & CoCo Uploader

유튜브 채널 Toto & CoCo 의 영상을 업로드하는 개인용 도구입니다.
A personal tool that uploads videos to the YouTube channel Toto & CoCo.

무엇을 하는 앱인가 / What it does

  • 제작이 끝난 영상 파일을 운영자 본인의 YouTube 채널에 업로드합니다.
  • 업로드한 영상의 제목·설명·태그·언어 설정이 제대로 들어갔는지 되읽어 확인합니다.
  • 사용자는 채널 운영자 본인 한 명뿐입니다. 일반에 공개된 서비스가 아닙니다.
  • Uploads finished video files to the operator's own YouTube channel, then reads the video back to confirm the metadata was stored correctly. The only user is the channel operator.

사용하는 Google 권한 / Google scopes used

  • youtube.upload — 영상을 업로드합니다.
  • youtube.readonly — 업로드한 영상의 설정을 되읽어 확인합니다.
